# Reels explicativos

Reels animados para tu cuenta, hechos en tu ordenador por la IA que ya usas.

1. Descomprime esta carpeta donde quieras.
2. Ábrela en tu IA: la pestaña Code de la app de Claude, o Codex en la app de ChatGPT.
3. Escribe «configúrame». Instala lo que falte y te abre una página para tu clave de ElevenLabs.
4. Pide tu vídeo: «Hazme un vídeo sobre por qué el cielo es azul». Si tienes un reel que te guste, pásale el enlace
   («hazlo como este»): sale mejor copiando la forma de un vídeo que ya funcionó. Si no, elige uno de los suyos.

Antes de hacer el vídeo entero te enseña el guion y, luego, el hook con un trozo, para que digas si va por ahí. Los
vídeos terminados quedan en `trabajo/salida/`, con su portada y el texto del post. Nada se publica solo, y tus claves
no salen de tu ordenador.

Hecho con HyperFrames (Apache-2.0, https://github.com/heygen-com/hyperframes).
